# Google Play release notes, 1.0.4

Paste the block below into the release's **Release notes** box in Play Console (GOOGLE-PLAY.md,
section 9). Play allows 500 characters per language; this is about 150. The tag must match a
language the store listing has: the listing's default language is English (United Kingdom),
`en-GB`. If Play shows the tag as one it doesn't know, change it to the one Play lists.

Upload `release/1.0.4/uwucurrency-1.0.4.aab` (version code 15) with these notes, and
`uwucurrency-1.0.4-play-symbols.zip` as its native debug symbols.

```text
<en-GB>
New:
• API Docs in the edge tray opens the documentation for uwuCurrency's exchange rate API
</en-GB>
```
