# Google Play release notes, 1.0.2

Paste the block below into the release's **Release notes** box in Play Console (GOOGLE-PLAY.md,
section 9). Play allows 500 characters per language; this is about 300. The tag must match a
language the store listing has: the listing's default language is English (United Kingdom),
`en-GB`. If Play shows the tag as one it doesn't know, change it to the one Play lists.

Upload `release/1.0.2/uwucurrency-1.0.2.aab` (version code 13) with these notes, and
`uwucurrency-1.0.2-play-symbols.zip` as its native debug symbols.

```text
<en-GB>
Fixes:
• Screenshot a page in Report a bug now fills the picture, with no blank space around it
• On tablets, the converter is no longer cut off below From and To
</en-GB>
```
